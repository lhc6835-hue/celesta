# CELESTA — The Fallen Sky Vault

> 삼백 년 전, 하늘섬 왕국 셀레스타가 대지로 떨어졌습니다.
> 일곱 금고지기 가문이 봉인한 보물 상자들은 지금도 지층 깊은 곳에 잠들어 있죠.

곡괭이 한 자루와 랜턴 하나로 여섯 개의 지층을 파 내려가, 가장 깊은 곳의 **셀레스타의 심장**을 찾는 2D 픽셀 아트 발굴 게임입니다.
HTML 파일 하나로 돌아가며, 그래픽과 사운드·배경음악은 모두 브라우저 안에서 직접 그리고 합성합니다.

## 바로 플레이

- **GitHub Pages**: 저장소의 Pages 주소에서 바로 실행됩니다.
- **오프라인**: `index.html`을 내려받아 브라우저로 열면 됩니다.

## 특징

- **보물 상자 26종**: 나무상자부터 해파리 등불함, 일식의 성궤, 태초의 알, 셀레스타의 심장까지 상자마다 다른 개봉 연출이 있습니다.
- **열한 개의 등급**: 일반 · 고급 · 희귀 · 영웅 · 전설 · 신화 · 고대 · 천상 · 성좌 · 태초, 그리고 셀레스타의 심장만을 위한 **셀레스타** 등급.
- **열 개의 지층**: 들풀 표토 → 뼈의 지층 → 울림 수정굴 → 잿불 심층 → 셀레스타 유적층 → 별이 잠든 심연 → 가라앉은 하늘바다 → 태초의 숲 → 공허의 경계 → 왕좌의 금고. 층마다 타일, 원경, 배경음악이 다릅니다.
- **곡괭이 24종과 운명의 모루**: 강화는 수치만 올리고, 곡괭이 자체는 모루에서 벼려(뽑기) 얻습니다. 곡괭이마다 속도·행운·기름 절약·원석 보너스가 다릅니다.
- **보물 52종과 도감**: 찾은 상자는 도감에서 개봉 연출을 다시 볼 수 있습니다.
- **HUD**: 오른쪽 지층 위치 바(나중에 다른 플레이어 위치 표시용 `CELESTA_ONLINE.setPlayers()` 제공), 왼쪽 위 보물 나침반 다이얼.
- **튜토리얼**: 실제 지형 지도와 함께 모든 시스템을 설명하는 10쪽 안내(`H`).
- **화면 전환**: 금고 열쇠구멍 아이리스, 지층 흙더미 와이프, 지층 진입 배너.
- **계정과 클라우드 저장**: Google Sheets와 Apps Script로 만든 로그인·회원가입. 다른 기기에서도 이어서 할 수 있습니다.

## 계정 서버 만들기 (Google Sheets + Apps Script)

로그인 없이도 게임은 브라우저에 저장되며 그대로 플레이할 수 있습니다.
클라우드 저장을 쓰려면 아래처럼 서버를 한 번 만들어 주세요. 5분이면 됩니다.

1. [Google Sheets](https://sheets.new)에서 새 스프레드시트를 만듭니다. 이름은 자유입니다(예: `CELESTA Accounts`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)를 그대로 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고 유형으로 **웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인하면 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)이 나옵니다.
6. 게임 타이틀의 **SIGN IN** → 아래 **서버 설정**에 URL을 붙여 넣고 **저장 · 연결 확인**을 누릅니다.
   모든 플레이어가 같은 서버를 쓰게 하려면 `index.html`의 `const DEFAULT_API = '';`에 URL을 적어 두면 됩니다.

시트에는 `Users` 탭이 자동으로 만들어지고, 회원마다 한 줄씩 기록됩니다.

| 열 | 내용 |
|---|---|
| username | 아이디 (3~16자, 한글·영문·숫자·밑줄) |
| salt, hash | 사용자별 무작위 솔트와 SHA-256 500회 반복 해시. **비밀번호 원문은 저장하지 않습니다.** |
| createdAt, lastLogin | 가입·마지막 로그인 시각 |
| token, tokenExp | 기기별 로그인 토큰 (최근 5개 기기, 30일 유지) |
| save, savedAt | 게임 저장 데이터(JSON)와 저장 시각 |
| gold, opened, deepest | 한눈에 보는 진행 요약 |

### 보안 메모

- 로그인을 10분 안에 5번 틀리면 그 아이디는 10분 동안 잠깁니다.
- 통신은 Apps Script의 HTTPS로 이루어집니다.
- 시트 소유자는 해시와 저장 데이터를 볼 수 있으니, 다른 서비스와 같은 비밀번호는 쓰지 않도록 안내해 주세요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
