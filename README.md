# CELESTA — The Fallen Sky Vault

> 삼백 년 전, 하늘섬 왕국 셀레스타가 대지로 떨어졌습니다.
> 일곱 금고지기 가문이 봉인한 보물 상자들은 지금도 지층 깊은 곳에 잠들어 있죠.

곡괭이 한 자루와 랜턴 하나로 열 개의 지층을 파 내려가, 가장 깊은 곳의 **셀레스타의 심장**을 찾는 2D 픽셀 아트 발굴 게임입니다.
HTML 파일 하나로 돌아가며, 그래픽과 사운드·배경음악은 모두 브라우저 안에서 직접 그리고 합성합니다.

## 온라인 서버 (Cloudflare Workers + Durable Objects)

`server/` 폴더가 계정·저장·친구·실시간 멀티플레이를 맡습니다. 공식 서버는 `https://celesta-online.celesta.workers.dev`이고, `index.html`의 `DEFAULT_API`에 들어 있습니다.

| 구성 | 역할 |
|---|---|
| Worker | `/api`(가입·로그인·저장·친구·서버 목록 등)와 `/ws`(WebSocket) 입구 |
| `Directory` DO (1개) | 계정(PBKDF2-SHA256 + 사용자별 솔트 + 서버 비밀 pepper), 세션 토큰(기기별 5개·30일), 저장, 친구·초대, 개인 서버, 접속 상태, 순위 |
| `Room` DO (서버마다 1개) | 위치를 받는 즉시 같은 방에 중계, 파낸 칸 목록(서버 판정), 상자 선점, 채팅·이모트, 방장 강퇴 |

- 위치는 초당 15번(멈춰 있으면 2초마다) 보내고, 다른 사람은 100ms 뒤를 보간해 부드럽게 그립니다.
- 지형은 시드로 모두가 똑같이 만들고, 서버는 "비어 버린 칸" 목록만 들고 있습니다. 상자는 서버가 먼저 친 사람에게만 열어 주고, 보상 굴림 씨앗도 서버가 줍니다.
- 끊기면 자동으로 다시 연결하고, 그동안 판 칸은 모아 뒀다가 보냅니다.
- 온라인 동안 혼자 하던 발굴지는 그대로 보관되고, 나오면 원래 자리로 돌아갑니다. 곡괭이·셀라·도감은 어디서든 이어집니다.
- claude.ai 아티팩트 화면에서는 외부 연결이 막혀 있어 혼자 하기만 됩니다. Pages 주소나 내려받은 HTML에서 온라인을 쓸 수 있습니다.

직접 띄우려면:

```bash
cd server
npm install
npx wrangler login            # 또는 CLOUDFLARE_API_TOKEN 환경 변수
npx wrangler deploy
openssl rand -hex 32 | npx wrangler secret put PEPPER
```

배포된 주소 뒤에 `/api`를 붙여 게임의 **SIGN IN → 서버 설정**에 넣거나, `index.html`의 `DEFAULT_API`를 바꾸면 됩니다.

## 예전 계정 서버 (Google Sheets + Apps Script)

처음에는 아래 구글 시트 서버를 썼습니다. 지금은 새 서버가 처음 로그인하는 옛 계정을 여기서 확인해 옮겨 오는 용도로만 남아 있습니다.

만드는 방법은 다음과 같습니다.

1. [Google Sheets](https://sheets.new)에서 새 스프레드시트를 만듭니다. 이름은 자유입니다(예: `CELESTA Accounts`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)를 그대로 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고 유형으로 **웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 승인하면 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)이 나옵니다.
6. 새 서버의 `server/wrangler.toml`에 있는 `SHEETS_API`에 이 URL을 넣으면, 이 시트의 계정이 첫 로그인 때 옮겨집니다.

시트에는 `Users` 탭이 자동으로 만들어지고, 회원마다 한 줄씩 기록됩니다.

| 열 | 내용 |
|---|---|
| username | 아이디 (3~16자, 한글·영문·숫자·밑줄) |
| salt, hash | 사용자별 무작위 솔트와 SHA-256 500회 반복 해시. **비밀번호 원문은 저장하지 않습니다.** |
| createdAt, lastLogin | 가입·마지막 로그인 시각 |
| token, tokenExp | 기기별 로그인 토큰 (최근 5개 기기, 30일 유지) |
| save, savedAt | 게임 저장 데이터(JSON)와 저장 시각 |
| gold, opened, deepest | 한눈에 보는 진행 요약 |

### 보안 메모

- 로그인을 10분 안에 5번 틀리면 그 아이디는 10분 동안 잠깁니다.
- 통신은 Apps Script의 HTTPS로 이루어집니다.
- 시트 소유자는 해시와 저장 데이터를 볼 수 있으니, 다른 서비스와 같은 비밀번호는 쓰지 않도록 안내해 주세요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
